# Privacy policy draft

This independent watch face and companion guide do not create accounts, show advertisements, include analytics SDKs, request sensitive permissions, or collect/transmit personal data. The companion stores only its language preference locally. The watch uses device time, watch face style settings and system display mode. No health data is requested.

Opening the store button launches an external browser or Google Play. Purchases, store account information and store telemetry are handled by Google under its policies. This application does not process payment information.

Before publication, replace this draft with a publicly hosted policy identifying the actual developer/legal entity and its contact email. Do not submit this file with missing developer contact details as a final policy. Update it whenever behavior or SDKs change.
